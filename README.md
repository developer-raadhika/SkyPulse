🌤️ SkyPulse — Weather Beyond Numbers

SkyPulse is a responsive React weather application that turns real-time weather data into a simple and engaging experience. Search for any city to explore temperature, humidity, wind speed, pressure, weather conditions, day/night status, weather insights, and a personalized Today's Activity suggestion.

✨ Features

🔎 Search weather by city
🌡️ Real-time temperature & weather details
💧 Humidity, 💨 wind & pressure information
🌞 Day/Night detection
🌈 Dynamic weather-based background
💡 Smart Weather Insights
🎯 Today's Activity suggestions
📱 Fully responsive design
⚠️ Error handling for invalid cities

Built with: React.js • Axios • CSS • OpenWeatherMap API
